# Java Learning Journey — Shirt Stock Manager

A small Java project I built while learning **Object-Oriented Programming (OOP)**. It helps me practice creating classes and objects, using constructors and methods, and managing stock quantities.

## What I'm Learning

- Creating classes and objects in Java
- Defining attributes and constructors
- Writing and calling methods
- Managing stock quantities
- Displaying object information
- Practicing basic OOP concepts through a mini-project

## Project Overview

The project represents shirts in a simple stock management system.

Each shirt has the following attributes:

| Attribute | Type | Description |
|---|---|---|
| `id` | `int` | Shirt identifier |
| `prix` | `double` | Shirt price |
| `couleur` | `String` | Shirt color |
| `quantite` | `int` | Available quantity |

### Features

- Create shirt objects with different properties
- Add shirts to stock
- Decrease stock quantity when a shirt is removed
- Display shirt information

## How to Run

1. Open the project in **Apache NetBeans** or another Java IDE.
2. Make sure `Chemise.java` and `TestChemise.java` are in the same package.
3. Run `TestChemise.java` to test the program.
